# ARCWANE - Artbook 2026

Интерактивная иллюстрированная книга мира Арквейн.

## Редакция 11

- Эхоры - фракция (знак: сосуд из двух разомкнутых дуг с камертоном; он же на всех знамёнах). Внутри два течения: Канон (Верхний Кальциар, правитель Сигиллат) и Хор Раскола (Нижний Кальциар, предводитель Эйрат).
- Порядок главы: общее о народе → Перемирие Звона → Канон → Раскол → Хор Раскола → Армия Канона (6) → Армия Хора (6) → финал.
- Эйрат: Хранитель Скола и Голос Скола. Обе формы Эйрата и Сигиллата стоят на одном развороте (слева и справа).
- Новые существа Канона: Глазуровщик, Ловчий, Обжигатель. Существа Канона и Хора нарисованы в разных ракурсах; Обжигатель - ходячая печь, а не рыцарь.
- Все новые иллюстрации лежат в assets/. Под текстом добавлено затемнение для читаемости.

## Запуск

Откройте `index.html` после распаковки. Сборка и установка зависимостей не нужны.

## Управление

Нажмите обложку, потяните угол страницы, используйте стрелки клавиатуры или свайп. «Содержание» открывает список страниц. Нажатие на свободную область иллюстрации открывает полный арт. Home возвращает на обложку, End - к последнему развороту.

## Редактирование

`book-data.js` - порядок, тексты и ссылки на изображения; `style.css` - оформление; `reader.js` и `page-fold.js` - чтение и перелистывание; `assets/` - иллюстрации.

Для будущих фракций используйте последовательность: знакомство → происхождение народа → условия возникновения фракции → поворотное событие → принципы → столица и быт → герои и роли → конфликт → переход к следующей истории. Сначала объясняйте термин в повествовании, затем показывайте его в конкретной сцене.
